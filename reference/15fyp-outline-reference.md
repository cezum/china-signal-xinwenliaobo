## 核心目标（第三章）
- 高质量发展：GDP保持合理增长区间，全要素生产率稳步提升
- 科技自立自强：全社会研发经费投入年均增长7%以上
- 全面深化改革：社会主义市场经济体制更加完善
- 人民生活品质：城镇调查失业率低于5.5%，人均预期寿命提高到80岁
- 美丽中国：碳达峰目标如期实现，单位GDP二氧化碳排放降低17%
- 国家安全：粮食综合生产能力达1.45万亿斤左右，能源综合生产能力达58亿吨标准煤

## 项目指令重点产业清单对标参考
- 人工智能+行动 → 第二篇（新兴产业和未来产业）、第四篇（数智赋能）
- 量子科技/可控核聚变/脑科学 → 第二篇（未来产业）、第三篇（原始创新）
- 新能源（氢能/储能/SAF） → 第二篇（新兴产业）、第十三篇（绿色转型）
- 半导体/集成电路 → 第二篇（新兴产业）、第三篇（体系化创新）
- 生物医药 → 第二篇（新兴产业）、第十一篇（健康中国）
- 高端装备/商业航天/低空经济 → 第二篇（新兴产业和未来产业）
- 数字经济（数据要素/算力/6G） → 第四篇（算力算法数据、数智赋能）
- 绿色转型（碳达峰/循环经济） → 第十三篇（全面绿色转型）
- 农业现代化（种业/智慧农业） → 第八篇（农业农村现代化）
