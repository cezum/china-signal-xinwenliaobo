# 叙事框架判定词典（v1.0 | 2026-08-13）

> 用途：把"叙事框架"从每日 LLM 现判改为**词典为主、LLM 兜底、依据必填、冲突告警**，防止跨期判定漂移。

---

## 一、判定流程

1. **词典匹配**：对信号原文/联播条目做关键词匹配，命中即记录命中词，作为 `framework_evidence`
2. **LLM 兜底**：无词典命中或语境存疑时，由 LLM 判定，但必须引用原文片段作为依据
3. **依据必填**：每个主题的框架标签必须带 `framework_evidence`（命中词或原文片段），空依据 = 待补证
4. **冲突告警**：新判定与历史判定+依据冲突时，区分"叙事真变（记框架变更事件）"与"疑似漂移（要求人工确认）"

## 二、四框架词典

### 安全框架（最高优先级：守底线、不计成本）

### 竞争框架（高优先级：资源倾斜、抢位）

---

## 三、冲突规则

1. 同一文本命中多框架时，**按语境主次记录双标签**（如"安全+发展"），日报须说明主次
2. 无明确主次时按优先级：**安全 > 竞争 > 民生 > 发展**（安全叙事通常伴随最高执行优先级）
3. 关键字"兜底/保障/有序"出现在能源、粮食、应急语境 → 安全框架；出现在养老、医疗、救助语境 → 民生框架；判不定时交给 LLM 并引用原文
