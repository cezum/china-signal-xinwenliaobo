# 历史转向回测方案（backtest plan）

**定稿日期：** 2026-08-16
**状态：** 三案例初步报告已生成。2021–2025 语料回填完成（成功 1636 天，缺失 190 天），正式词频统计、图表与房地产/新能源/平台经济报告已产出；缺口声明已写入报告。
**用途：** 用 2021–2025 联播文字稿验证检测方法能否事后捕捉三个已知政策转向；产出开源发布的核心分发资产"已知转向回测报告"。

---

## 一、回测证明什么、不证明什么

| 证明 | 不证明 |
|---|---|
| 联播文本**能**事后捕捉已知政策转向（检测器不是事后诸葛亮自嗨） | 投资假设能赚钱 |
| "实际变了但没说"在真实数据里可检测、可复现 | 未来预测一定准 |
| 方法论在**样本外**（历史）有效 | 整个项目值得所有人用 |

发布口径必须是"对历史的复盘"，不是"对未来的预测"。

## 二、工作流

```
1. 烟雾测试：4 个跨年样本日期各抓一次，确认历史页面可用、解析质量合格
   （2021-06-15 / 2022-11-03 / 2023-04-20 / 2024-09-26）
2. 全量回填：backfill_xwlb.py --start 2021-01-01 --end 2025-12-31
   （断点续传，失败日期进缺口清单；先跑 2024–2025 亦可，见第六节）
3. 词频统计：keyword_stats.py --start 2021-01-01 --end 2025-12-31
   （零 LLM，纯本地计数，输出月度 CSV + 首现日期 + 缺口清单）
4. 生成图表：backtest_charts.py（零依赖 SVG 双线图 + index.html）
5. 人工分析：看曲线、对照已知时间线、写发现
6. 报告：按 report_template.md 填空
```

## 三、三个案例与词表（已冻结）

词表存于 [`keywords.json`](./keywords.json)，由脚本读取。人工审阅版：

### ① 房地产：房住不炒 → 止跌回稳（措辞逆转型）

| 组 | 词 |
|---|---|
| 旧政策组 | 房住不炒、长效机制、因城施策、调控、严控、抑制 |
| 新政策组 | 止跌回稳、平稳健康、保交楼、白名单、城中村改造 |

看点：旧组归零时点 vs 新组首现时点；「房住不炒」最后一次出现若早于 2024-09 官方改口，即"叙事先于表态"的证据。

### ② 平台经济：整改 → 规范健康发展（整改→支持型）

| 组 | 词 |
|---|---|
| 整改组 | 反垄断、防止资本无序扩张、二选一、整改 |
| 支持组 | 平台经济、规范健康发展、鼓励、创新活力 |

看点：整改组消失与支持组复现之间的时间差。

### ③ 新能源：扶持 → 反内卷（框架迁移型）

| 组 | 词 |
|---|---|
| 扶持组 | 新能源、双碳、补贴、加快、大力发展 |
| 整顿组 | 反内卷、产能过剩、恶性竞争、合理布局 |

看点：同一产业从"加快"措辞迁到"整顿"措辞的交叉点。

### 词表噪音说明

「调控」「加快」「鼓励」等词偏宽，第一轮计数后如噪音过大（命中大量无关条目），微调词表重跑即可——计数是分钟级任务，调词重数零成本。

## 四、脚本说明

| 脚本 | 职责 | 依赖 |
|---|---|---|
| `scripts/backfill_xwlb.py` | 批量回填 2021–2025 文字稿，断点续传、缺口清单、礼貌限速 | 仅调用 `fetch_xwlb.py` 的 CLI（`--date`/`--outdir`/`--force`/`--source`），不 import 其内部函数 |
| `scripts/keyword_stats.py` | 从本地语料计数词频，输出月度 CSV、首现日期、缺口清单 | 零依赖（标准库），不 import `common.py` |
| `scripts/backtest_charts.py` | 从月度 CSV 生成零依赖 SVG 双线图与 index.html | 零依赖（标准库），不 import `common.py` |

两脚本均只**新增**文件、不修改任何现有脚本；不挂任何 workflow，不会自动运行。

## 五、已知风险与对策

1. **历史页面可用性未知**：CCTV 旧页面可能 404 或 HTML 结构与 2026 不同；脚本有 mrxwlb 备份源自动降级。对策：先做第一节烟雾测试，确认双源可用性与解析质量。
2. **词表噪音**：见第三节；第一轮数据出来后人工抽查。
3. **缺口**：语料缺天会如实写入缺口清单，报告中必须声明"N 天成功 / M 天缺失"，否则数据洁癖者会挑刺。
4. **版权**：转录原文只存本地 `data/raw/`（已 gitignore），**永不入库**；公开的只有词频统计、图表与报告。

## 六、分阶段执行

1. 烟雾测试 4 个样本日期（约 10 分钟）。
2. 先跑 **2024-01-01 → 2025-12-31**（约 730 天），覆盖①房地产改口、③新能源反内卷，出两案例报告验证全流程。
3. 向前扩展到 **2021-01-01 → 2023-12-31**，补全②平台经济，出三案例完整报告。
4. 全部完成后再谈发布。

## 七、发布口径备忘
