# 如何看懂这份雷达

> 这里不是复述《新闻联播》，而是持续检测政策叙事在“悄悄加码、被搁置、转向或改口”。

## 1. 日报怎么看

每日日报按“先结论、后证据”组织：

- **今日一句**：当天最值得记住的一个变化。
- **今日速览**：每条信号只回答三件事——联播怎么说、行业传导是什么、接下来盯什么。
- **证据与方法底稿**：点击折叠块可以看到联播原文、维度标签、框架命中词、投资假设和验证条件。
- **风险与验证打卡**：哪些假设已验证，哪些进入待复核，哪些现实风险正在推动政策。

普通人读“今日一句 + 今日速览”就够了；想较真的人点开折叠块看证据。

## 2. 关键术语的人话版

### 层级：谁在说

| 标签 | 含义 |
|------|------|
| A | 最高层讲话、批示或头条部署 |
| B | 专题报道 + 部委文件，通常是最新定调后的落地 |
| C | 部委自主发布的文件或规划 |
| D | 简讯、快讯 |

### 首次性：是不是新东西

| 标签 | 含义 |
|------|------|
| NEW | 新方向首次出现 |
| PROGRESS | 老方向有新进展 |
| REPEAT | 重复报道，无新增信息 |

### 具体性：有没有抓手

| 标签 | 含义 |
|------|------|
| S1 | 有量化指标、时间表、资金或项目 |
| S2 | 方向明确，但缺细节 |
| S3 | 只有方向性表态 |

### 政策窗口：短期出细则的概率

| 标签 | 含义 |
|------|------|
| 开放 | 问题、方案、政治时机三流齐备，短期落地概率高 |
| 接近 | 方向明确，但差一个推力 |
| 封闭 | 暂不具备落地条件 |

### 验证窗口：多久能验证

| 标签 | 时间尺度 |
|------|----------|
| SHORT | 1–4 周 |
| MID | 1–3 个月 |
| LONG | 无明确节点 |

## 3. 叙事框架

联播用不同话术给政策定优先级。框架迁移比单次报道更重要。

| 框架 | Emoji | 常见含义 |
|------|-------|----------|
| 安全 | 🛡️ | 守底线，优先级最高，通常“不计成本” |
| 竞争 | 🏆 | 抢位、砸资源，力争领先 |
| 民生 | 🏠 | 兜底保障，稳步推进 |
| 发展 | 📈 | 培育壮大，市场化推进 |

例如：核电从“竞争框架”转向“安全框架”，意味着它可能从“发展产业”升级为“必须保证”，这就是一个强信号。

## 4. 极简跟踪表怎么看

`tracking.md` 是自动生成的 5 列极简表，只回答“现在正在跟什么、等什么”。

### 风向图例

| Emoji | 含义 |
|-------|------|
| 🟢 抓紧落 | 跟踪中 + 政策窗口开放 |
| 🟡 等风来 | 跟踪中 + 政策窗口接近 |
| ⚪ 暂缓 | 跟踪中 + 政策窗口封闭 |
| 🟠 延迟核验 | 验证日已过，仍处宽限期 |
| 🔍 待复核 | 宽限期已过，等人工核验 |
| ✅ 已验证 | 验证条件已满足 |
| 💡 线索 | 已验证且值得继续深入 |
| ❌ 证伪/衰减 | 假设被证伪或信号衰减 |
| 🗄️ 归档 | 已移出主跟踪表 |

完整字段和证据仍在 `reference/initial_signal_tracking_table.md`。

## 5. 这套雷达不能证明什么

它跟踪的是官方叙事轨迹，不是产业现实本身。联播说“加快”“加强”，不等于订单、产量、利润立刻兑现；联播不再提一个词，也可能只是编排变化，而不是政策取消。

因此，验证层会把“联播是否报道”和“官方事实是否发生”分开处理：

- **联播型验证点**：验证事件本来就应当出现在联播，证据只看当日联播。
- **外部型验证点**：验证事件来自部委、统计局等外部官方源；即使联播没报道，也要以官方公开信息为准。

研究、学习用途；不构成投资建议。
