# 新闻联播风向标 | 2026-08-19

## 今日要点

今日联播头条聚焦自贸试验区制度型开放深化，习近平总书记指示深入推进制度型开放，23个自贸试验区以制度创新为核心，临港离岸贸易结算从三天缩短为三秒，北京数据出境负面清单扩围，海南零关税覆盖率提升至74%。这标志着我国对外开放从商品和要素流动型开放向规则、规制、管理、标准等制度型开放转变，自贸试验区作为改革开放试验田的作用进一步凸显。

商业航天领域迎来重大突破，朱雀三号火箭首次实现陆地回收，标志着我国重复使用火箭技术迈入工程化验证阶段，为大型星座组网和规模化商业发射提供运力支撑。嫦娥七号器箭组合体完成垂直转运，计划近日择机发射，月球南极探测任务进入倒计时。两项航天进展叠加，显示我国商业航天与国家深空探测双线并进，航天产业链有望持续受益。

服务业扩能提质成为另一亮点，前7个月信息传输、软件和信息技术服务业生产指数同比增长10.6%，知识密集型服务出口占比超一半，生产性服务业加速嵌入制造业出海全流程。同时，交通运输部发布'十五五'精品自驾旅游公路规划，构建约6万公里'三环、四横、五纵'主骨架，将带动沿线旅游基础设施投资。

本报告每日跟踪新闻联播中的政策信号，信号提取标准为：有政策载体、有新信息、能写出可证伪的产业验证假设、可验证、相对跟踪表有信息增量。

**固定口径表：**

| 维度 | 口径 |
|------|------|
| 层级 | A=总书记讲话/最高层部署；B=专题报道+部委文件；C=常规报道+部委文件/规划；D=简讯快讯 |
| 首次性 | NEW=首次出现；PROGRESS=已有方向新进展；REPEAT=重复 |
| 具体性 | S1=量化指标+时间表+资金/项目；S2=有量化指标或时间表；S3=只有表态 |
| 政策窗口 | 开放=问题流/政策流/政治流三流齐备；接近=缺一个推力；封闭=不具备 |
| 验证窗口 | SHORT=1-4周；MID=1-3月；LONG=无明确节点 |
| 叙事框架 | 安全/竞争/民生/发展，依据框架判定词典命中词 |
| 投资假设 | 内部可证伪验证指标，不对外推送 |
