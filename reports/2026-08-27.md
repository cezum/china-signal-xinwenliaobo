## 读报指南（怎么读这份报告）

本报告为政策偏离检测工具，跟踪“规划承诺 vs 联播叙事 vs 现实兑现”之间的偏差。核心口径如下：

| 维度 | 口径 |
|------|------|
| 层级 | A=总书记讲话/最高层部署；B=专题报道+部委文件；C=常规报道+部委文件/规划；D=简讯快讯 |
| 首次性 | NEW=首次出现；PROGRESS=已有方向新进展；REPEAT=重复 |
| 具体性 | S1=量化指标+时间表+资金/项目；S2=有量化指标或时间表；S3=只有表态 |
| 政策窗口 | 开放=问题流/政策流/政治流三流齐备；接近=缺一个推力；封闭=不具备 |
| 验证窗口 | SHORT=1-4周；MID=1-3月；LONG=无明确节点 |
| 叙事框架 | 安全/竞争/民生/发展，依据框架判定词典命中词或原文片段 |
| 投资假设 | 内部可证伪验证指标，不构成投资建议 |
| 框架判定依据 | 词典命中词或原文片段，空依据=待补证 |
| 生命周期事件 | 建档/框架变更/状态变更/验证等，只追加不覆盖 |

### 信号1：机器人产业创新与具身智能规模化应用进入验证密集期

**联播原文：** 第9条——2026年上半年机器人产业规模以上企业营收1655亿元，同比增长24.5%；北京建成电力具身智能中试验证平台，已开放近300种场景完成首试首用；深圳“72小时打样圈”企业从设计到3D打印样机最快3天；我国已成为全球机器人专利最大拥有国，2024年专利申请量约占全球三分之二；自主品牌工业机器人国内市场占有率突破50%，连续13年成为全球最大工业机器人市场；2025年工业机器人出口增长48.7%，首次超过进口。“十五五”规划纲要已将具身智能纳入未来产业重点战略布局；今年6月工信部、国资委启动人形机器人与具身智能实景实训专项行动，目标到2026年底凝练百个以上高价值应用场景，带动万台级规模落地能力。

**趋势判断：** 机器人产业从“技术突破”进入“规模化应用”阶段。产业端数据（营收、出口、市场占有率）与场景端进展（中试验证平台、实景实训专项行动）同步推进，且“十五五”规划纲要已将具身智能纳入未来产业重点战略布局，政策与产业形成共振。主题56自建档以来首次出现完整产业数据与专项行动目标，验证窗口明确。

**投资假设：** 具身智能获政策倾斜 → 机器人核心零部件（减速器、伺服驱动、控制器）与中试验证平台订单/数据加速。

### 信号2：中小微企业贷款贴息新政落地执行

**联播原文：** 第8条——工商银行、农业银行、中国银行等六大商业银行发布公告，中小微企业贷款和服务业经营主体贷款贴息政策已落地执行。对于8月1日以来发放的符合条件的中小微民营企业流动资金贷款，中央财政按贷款本金给予年化1个百分点、期限不超过2年的贴息支持，系财政贴息首次扩大至中小微民营企业流动资金贷款。单户企业贴息贷款规模上限由每年5000万元提高至7500万元（服务业由1000万元提高至2000万元）。8月1日至公告发布前已办理的贷款，银行将符合条件业务报送审核，无需企业操作。

**趋势判断：** 贴息政策从“发布”进入“执行”阶段。六大行同步公告意味着政策已进入实操层面，且“无需企业操作”的自动报送机制降低了政策落地摩擦。财政贴息首次覆盖中小微民营企业流动资金贷款，是财政货币政策协同发力的新工具，与主题38（国务院第十二次全体会议部署增量政策）形成呼应。

**投资假设：** 财政贴息扩大至中小微民营企业流动资金贷款 → 中小微企业信贷投放规模与经营活力数据加速。

**层级/首次性/具体性/验证窗口：** B / PROGRESS / S1（量化指标+时间表）/ SHORT（政策已执行，效果数据待观察）

### 信号3：高耗能行业节能降碳攻坚行动启动

**联播原文：** 第11条——国家正式启动为期三年的节能降碳攻坚行动，覆盖钢铁、水泥等九大高耗能产业，三年内推动低效产能清零。上半年重点钢企能耗持续下降，余热余压回收自发电比例超六成，三年极致能效工程累计减排二氧化碳6000万吨；成都南玻新一代玻璃熔窑智能燃烧系统投入运行，每年可减排二氧化碳超2万吨；重庆华新地维水泥厂化石燃料替代率突破65%。预计到2030年废钢年回收利用量达3亿吨，废纸、废塑料年回收利用量分别达8000万吨、2200万吨，再生有色金属年产量达2500万吨。

**趋势判断：** 节能降碳攻坚行动从规划进入实施阶段。三年行动方案覆盖九大高耗能产业并明确“低效产能清零”目标，具体项目（智能燃烧系统、大比例燃料替代技术）已落地产生减排数据。与主题23（碳达峰与全面绿色转型）形成政策接力，但攻坚行动更聚焦高耗能行业存量改造。

**投资假设：** 节能降碳攻坚行动启动 → 高耗能行业节能改造、固废资源化利用、清洁能源替代项目投资加速。

**层级/首次性/具体性/验证窗口：** B / PROGRESS / S1（量化指标+时间表）/ MID（三年行动周期）

**政策窗口：** 开放——问题流（高耗能行业减排压力）、政策流（三年攻坚行动）、政治流（双碳目标约束）三流齐备。

**叙事框架：** 安全框架——命中“安全”“保供”“底线”；原文“高耗能行业加速推进节能降碳”“三年内将推动低效产能清零”。

**待验证：** 需观察攻坚行动具体项目落地情况与高耗能行业节能降碳数据（重点钢企能耗、固废综合利用率）。已纳入跟踪表主题58（首次纳入）。

**趋势判断：** 都市圈1小时通勤圈建设从规划进入工程实施阶段。22号线空载试运行是京津冀率先突破的标志性节点，年底具备开通条件的目标明确。该主题与主题29（西部综合立体交通网）同属交通基础设施投资主线，但聚焦都市圈通勤场景，政策着力点更具体。

**投资假设：** 都市圈1小时通勤圈建设推进 → 城际轨道交通建设、跨省公交运营、枢纽站场改造等实物工作量加速。

**层级/首次性/具体性/验证窗口：** B / PROGRESS / S1（量化指标+时间表）/ MID（2030年覆盖率目标）

**政策窗口：** 开放——问题流（都市圈通勤需求）、政策流（实施方案+22号线项目）、政治流（区域协调发展战略）三流齐备。

**叙事框架：** 发展框架——命中“加快构建”“现代化”“新格局”；原文“我国都市圈加快推进1小时通勤圈建设”“充分释放都市圈对区域协调发展的带动作用”。

**待验证：** 需观察22号线年底是否如期开通运营，以及其他都市圈通勤项目开工进展。已纳入跟踪表主题59（首次纳入）。
