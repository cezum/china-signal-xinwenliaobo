## 读报指南（怎么读这份报告）

> 首次阅读先看这里，老读者可跳过。本报告从联播中提取的是"政策信号"——有政策含义、可追踪验证的事件，不是每条新闻都算。跟踪表中的"主题N"为信号编号，主题详情及历史时间线见 `reference/initial_signal_tracking_table.md`。

| 口径 | 含义 |
|------|------|
| 层级 | 信号由谁发出：A=总书记讲话/最高层部署；B=最高层定调后的部委落地；C=部委自主发布；D=简讯快讯 |
| 首次性 | 是不是新方向：NEW=首次出现的新信号；PROGRESS=已有方向的新进展；REPEAT=重复无新增 |
| 具体性 | 有没有抓手：S1=有量化指标/时间表/项目；S2=方向明确但缺细节；S3=只有方向表态 |
| 政策窗口 | 出细则的概率：开放=问题、方案、政治时机三流齐备，短期落地概率高；接近=差一个推力；封闭=暂不具备条件 |
| 验证窗口 | 多久能验证：SHORT=1-4周；MID=1-3个月；LONG=无明确节点 |
| 叙事框架 | 联播报道的话术基调：安全框架（守住底线/自主可控）、竞争框架（抢占/引领）、民生框架（兜底/保障）、发展框架（培育/壮大） |
| 投资假设 | 每个主题一句话的投资/产业逻辑；跟踪表的验证日期就是检验这句假设的时点，不是事件打卡 |
| 框架判定依据 | 框架标签的证据（命中词典词或原文片段）；无依据=待补证，词典见 `reference/framework-dictionary.md` |
| 生命周期事件 | 分析模型自己的状态变更记录（建档/框架变更/状态流转），区别于时间线（时间线记联播事件，生命周期记我们的分析决策） |

## 信号详析

### 信号一：西部综合立体交通网建设纵深推进——平陆运河即将通航

- **联播原文：** 第1条【新思想引领新征程】——习近平总书记强调"坚持以大开放促进大开发"，十五五开局之年西部交通网建设加快向西部纵深推进。平陆运河今日启动全线实船试验（通航前最后一次"大考"），9月通航后将成为西南地区通往东盟运距最短、最经济、最便捷的水运通道。西部城区常住人口超10万的市县高速公路通达率从五年前95%提升至99%以上；铁路营业里程从5.91万公里增至6.73万公里，占全国四成有余。到2030年，八纵八横高铁主骨架将覆盖西部主要城市。

- **趋势判断：** 这是"十五五"开局之年区域协调发展的标志性进展。平陆运河是西部陆海新通道的骨干工程，9月通航将打通西南经北部湾直达东盟的水运捷径，战略意义不仅在于交通本身，更在于为西部大开发提供外向型经济出海口。99%的高速公路通达率和6.73万公里铁路里程是硬基础设施指标，说明西部交通正从"基本联通"迈向"高效覆盖"。信号验证窗口极近——平陆运河下月即可验证。

- **投资假设：** 西部陆海新通道打通西南出海捷径 → 通航后货运量与沿线产业布局决定港口、物流与沿线制造业的投资兑现（通航日期已公告，验证点放在通航后的经济结果，而非通航本身）。

- **层级/首次性/具体性/验证窗口：** A / NEW / S1（量化指标+时间表+具体项目） / SHORT（平陆运河9月通航）

- **政策窗口：** 开放。十五五开局之年，问题流（西部交通短板）、政策流（国家规划纲要+领导人指示）、政治流（西部大开发新格局）三流齐备。

- **叙事框架：** 发展框架（区域协调发展、西部大开发）。判定依据：命中发展词典词"以大开放促进大开发/纵深推进"。无框架迁移。

- **待验证：** 平陆运河通航后的货运量数据及西部陆海新通道沿线产业布局进展（通航日期已公告，不作为验证点）。已纳入跟踪表主题29（首次纳入）。

### 信号二：核电建设规模居世界第一——十五五首批8台机组核准

- **联播原文：** 第5条——我国核准在建核电机组达57台，在建规模占全球一半以上；在运和核准在建核电机组总装机规模1.35亿千瓦，居世界第一。核电以不到2%的装机占比贡献近5%的发电量，广东、福建、辽宁、海南4省份核电发电量占比均超15%。7月底新核准8台核电机组，为"十五五"时期首批核准项目。十五五期间继续"积极安全有序发展"，稳步推进东部沿海核电带建设，因地制宜推进核能综合利用。

- **趋势判断：** 核电建设正从"规划蓝图"进入"规模化落地"阶段。57台在建机组、1.35亿千瓦总装机、十五五首批8台核准——三个数据共同构成一个清晰的加速曲线。值得关注的是叙事框架的分化：跟踪表主题9（清洁能源产业集群）以"竞争框架"定位，聚焦风电、光伏等增量赛道的产业竞争；而核电报道强调"积极安全有序"和"沿海核电带"，其底色是能源安全与核安全，属安全框架。这意味着能源政策正在形成"竞争+安全"双轨叙事——增量赛道讲竞争，基荷电源讲安全。

- **投资假设：** 核电纳入安全框架（最高优先级）→ 核准与开工节奏决定核电设备、建设与运营产业链的订单起点。验证点不是"核电有没有进展"，而是安全化叙事有没有兑现为实物工作量。

- **层级/首次性/具体性/验证窗口：** B / PROGRESS / S1（57台在建、1.35亿千瓦、8台新核准、2%装机贡献5%发电） / MID（1-3月内新项目里程碑）

- **政策窗口：** 开放。十五五首批核准已落地，后续项目管线明确。

- **叙事框架：** 安全框架（能源安全+核安全）。判定依据：命中安全词典词"积极安全有序发展/安全"；与主题9的分化依据为叙事语境（东部沿海核电带、基荷电源）。**注意：与跟踪表主题9（清洁能源，竞争框架）形成框架分化**——同一能源领域出现两种叙事，增量赛道讲"竞争"，基荷电源讲"安全"，是当前能源政策最清晰的结构性特征。已纳入跟踪表主题30（首次纳入）。

- **待验证：** 东部沿海核电带新项目开工进展；核能综合利用（供暖、海水淡化等）示范项目落地。

### 信号三：汽车出口连续两月破百万辆——新能源占比过半

- **联播原文：** 第4条——7月份汽车出口104.3万辆（同比+81.3%），连续两个月突破100万辆。新能源汽车出口55.3万辆（同比+145.5%），占比连续两月突破50%。中汽协分析：中国拥有全球最完整汽车产业链（从锂矿加工到整车组装），供应链抗风险能力强；智能化形成核心竞争力，智能驾驶、座舱交互快速迭代适配海外需求。

- **趋势判断：** 汽车出口连续两月破百万是一个产业里程碑。新能源占比过半意味着中国汽车出海已从"性价比驱动"转向"技术驱动"，智能驾驶和座舱交互成为核心卖点。不过需注意，本条信号的政策载体是中汽协行业数据而非政府政策文件，层级为C；其跟踪价值在于作为产业竞争力的实时晴雨表，而非政策动向本身。

- **投资假设：** 汽车出海从性价比转向技术驱动 → 出口量与新能源占比的月度数据检验智能化产业链的海外盈利逻辑。该主题属产业数据观察：不做"事件验证"，用每月数据确认趋势是延续还是逆转。

- **层级/首次性/具体性/验证窗口：** C / PROGRESS / S1（104.3万辆、81.3%增速、新能源55.3万辆/145.5%、占比超50%） / SHORT（下月数据即可验证趋势延续性）

- **政策窗口：** 开放。汽车出海政策支持持续，产业链优势稳固。

- **叙事框架：** 竞争框架（全球产业链竞争、智能化核心竞争力）。判定依据：命中竞争词典词"核心竞争力/全球最完整产业链"。无框架迁移。

- **待验证：** 8月汽车出口数据是否延续百万辆级；新能源出口占比能否维持50%以上；主要出口目的地（东南亚、欧洲、拉美）的政策环境变化。已纳入跟踪表主题31（首次纳入）。
