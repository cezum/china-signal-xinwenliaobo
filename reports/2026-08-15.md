## 读报指南（怎么读这份报告）

> 首次阅读先看这里，老读者可跳过。本报告从联播中提取的是"政策信号"——有政策含义、可追踪验证的事件，不是每条新闻都算。跟踪表中的"主题N"为信号编号，主题详情及历史时间线见 `reference/initial_signal_tracking_table.md`。

| 口径 | 含义 |
|------|------|
| 层级 | 信号由谁发出：A=总书记讲话/最高层部署；B=最高层定调后的部委落地；C=部委自主发布；D=简讯快讯 |
| 首次性 | 是不是新方向：NEW=首次出现的新信号；PROGRESS=已有方向的新进展；REPEAT=重复无新增 |
| 具体性 | 有没有抓手：S1=有量化指标/时间表/项目；S2=方向明确但缺细节；S3=只有方向表态 |
| 政策窗口 | 出细则的概率：开放=问题、方案、政治时机三流齐备，短期落地概率高；接近=差一个推力；封闭=暂不具备条件 |
| 验证窗口 | 多久能验证：SHORT=1-4周；MID=1-3个月；LONG=无明确节点 |
| 叙事框架 | 联播报道的话术基调：安全框架（守住底线/自主可控）、竞争框架（抢占/引领）、民生框架（兜底/保障）、发展框架（培育/壮大） |
| 投资假设 | 每个主题一句话的投资/产业逻辑；跟踪表的验证日期就是检验这句假设的时点，不是事件打卡 |
| 框架判定依据 | 框架标签的证据（命中词典词或原文片段）；无依据=待补证，词典见 `reference/framework-dictionary.md` |
| 生命周期事件 | 分析模型自己的状态变更记录（建档/框架变更/状态流转），区别于时间线（时间线记联播事件，生命周期记我们的分析决策） |

**验证源分类（v2.4）**：验证点是"联播报道某事件"的为**联播型**，证据仅限当日联播原文；验证点是官方/外部事实（如"商务部发布数据""国务院印发文件"）的为**外部型**，当日联播未出现时可引用官方公开信息核验（须写明机构、发布日期、来源标题或链接），禁止无出处推测。

"十五五"指2026-2030年国民经济和社会发展第十五个五年规划（纲要2026年3月发布，18篇62章）。本报告每条信号都标注其对纲要哪一篇哪一章的落地关系：**主题首次纳入跟踪，不等于政策方向是新的**——多数是纲要既有部署进入实施或见效阶段。

## 信号详析

### 信号一：生态环境法典正式施行——生态治理进入法典化阶段

- **联播原文：** 第1条【新思想引领新征程】——今天（8月15日）是全国生态日，《中华人民共和国生态环境法典》正式施行，我国生态环境保护迈入法典化系统治理新阶段。习近平总书记指出，推动绿色发展，建设生态文明，重在建章立制，用最严格的制度、最严密的法治保护生态环境。全国415.3万家固定污染源纳入排污许可管理，从今天起持证排污单位分批更新排污许可电子证照，实现大气、水、土壤等全要素"一证式"管理；第三轮第六批中央生态环保督察持续动真碰硬；全国累计办理生态环境损害赔偿案件约7万件，涉及赔偿金额约355亿元。河湖长制（120余万名河湖长、130余万名林长）实践已写入法典。

- **趋势判断：** 生态环境法典是继环境保护法、长江保护法之后的制度集大成者，标志着生态治理从"单法修补"进入"法典化系统治理"。对产业的意义在于执行端：法典强调"长牙带刺"，把"严"的要求贯穿监管、服务、惩处各环节——排污许可"一证式"管理意味着固定污染源监管的技术化、信息化改造（自动监控、数据归集）是刚需；生态损害赔偿累计355亿元的盘子还在扩大，环境责任成本将内化进企业运营。这是环保产业从"工程驱动"向"合规驱动"切换的制度基础，也是跟踪表生态主题群（碳达峰/生态保护规划/核电）新增的法治维度。

- **投资假设：** 环境法典"长牙带刺"从严执法 + 排污许可"一证式"管理 → 污染源自动监控、环境监测与环保治理装备需求加速，生态损害赔偿机制扩大环境责任成本覆盖。

- **层级/首次性/具体性/验证窗口：** A / NEW / S1（415.3万家排污许可、7万件赔偿案件、355亿元金额） / SHORT（督察通报与证照分批更新1-4周内可见进展）

- **政策窗口：** 开放。法律已施行（问题流=执法"宽软松"、政策流=法典文本、政治流=生态日头条），执行端全面铺开。

- **叙事框架：** 安全框架。判定依据：无词典直接命中，LLM 兜底判定，引用原文片段"用最严格的制度、最严密的法治保护生态环境""筑牢中华民族永续发展的生态根基"——生态法治底线叙事；辅以发展框架（绿色发展，次）。与跟踪表主题23（碳达峰）、26（生态保护规划）安全框架一致，无漂移。

- **待验证：** 第三轮中央生态环保督察新一批问题通报；排污许可电子证照分批更新落地进展（检验从严执法是否转化为环保监测/治理需求）。已纳入跟踪表主题32（首次纳入）。

### 信号二：资源循环利用产业2030年8万亿目标——再生资源产业链首次量化

- **联播原文：** 第5条——2026年全国生态日主场活动在内蒙古呼伦贝尔市举办，主题"厚植中国式现代化的绿色底色"。国家发展改革委等多部门发布生态文明建设重要成果：2012年以来，我国以年均3.4%的能耗增速支撑年均6.1%的经济增长。进入"十五五"，将扎实开展碳达峰行动，科学开展碳达峰碳中和综合评价考核；统筹推进"能水粮地矿材"一体化节约；加快废旧机电设备、汽车、电器电子等重点再生资源拆解能力改造升级，支持资源循环利用领域全国重点实验室建设，力争到2030年，资源循环利用产业产值达到8万亿元。

- **趋势判断：** "8万亿元产值"是再生资源/循环经济领域首次出现的国家级量化目标——对比参考，2025年国内资源循环利用产业产值约4万亿，意味着"十五五"期间翻倍空间。落点明确：废旧机电、汽车、电器电子四类重点再生资源的拆解能力改造升级，叠加全国重点实验室的科技支撑。这与以旧换新政策形成闭环——以旧换新（消费端放量）→ 报废拆解（回收端扩容）→ 再生材料（供给端替代）。跟踪表主题22（以旧换新，消费侧）今日经外部核验转"已验证"（上半年带动销售1.1万亿、截至7/23超1.25万亿），本主题补齐回收侧，构成"消费-回收"政策链的完整映射。

- **投资假设：** 资源循环利用产业8万亿产值目标（2030）→ 废旧机电/汽车/电器电子拆解能力改造升级 + 资源循环利用全国重点实验室 → 再生资源回收拆解、动力电池回收、家电回收产业链订单加速。

- **层级/首次性/具体性/验证窗口：** B / PROGRESS / S1（8万亿、2030年时间表、四类再生资源、重点实验室） / MID（重点实验室与拆解改造项目1-3个月内可见立项）

- **政策窗口：** 开放。生态日部委发布为政策流信号，发改委主推，配套（实验室、改造升级）已在表述中。

- **叙事框架：** 发展框架。判定依据：命中发展词典词"改造升级"（"加快废旧机电设备、汽车、电器电子等重点再生资源拆解能力改造升级"）；"能水粮地矿材一体化节约"涉及资源节约语境（安全框架，次）。主次分明，发展为主。

- **待验证：** 资源循环利用领域全国重点实验室建设启动；重点再生资源拆解能力改造升级项目落地（检验8万亿目标是否转化为实物投资）。已纳入跟踪表主题33（首次纳入）。

### 信号三：完整社区建设扩面提质——社区服务设施补短板量化推进

- **联播原文：** 第7条——今年以来，各地积极创新举措，加快补齐社区养老、托育、便利店、停车、绿化等服务短板。按照计划，今年全国将在约1000个社区实施完整社区建设改造。截至6月底，全国新开工完整社区已超780个，增补社区公共服务设施1903个、便民商业服务设施1517个，新增社区公共活动场地和公共绿地671.5万平方米。不少城市推行成片连片改造。住房城乡建设部表示，下一步将重点实施完整社区建设扩面提质增效工程，完善社区的养老、托育等公共服务设施，推进社区服务智能化。

- **趋势判断：** 完整社区建设是住建部在"十四五"试点基础上转入规模化实施的城市社区工程：年内1000个社区、上半年已开工780+个，下半年进入收官与"扩面提质增效工程"启动的衔接期。它的产业意义在于：社区养老、托育设施是长护险（主题16）、养老服务体系落地的最小物理单元；成片连片改造与社区服务智能化（智慧社区）则与城市更新（主题18）的资金盘面部分重叠。量化进度完整（1903+1517+671.5万平米），是社区服务设施投资的直接先行数据。

- **投资假设：** 完整社区建设扩面提质增效 → 社区养老、托育、便民商业、停车、公共绿地设施补短板 → 社区服务设施工程、适老化与托育设备需求加速。

- **层级/首次性/具体性/验证窗口：** C / PROGRESS / S1（1000个社区、780+开工、1903/1517个设施、671.5万平米） / MID（年底千个社区收官与扩面提质增效工程方案）

- **政策窗口：** 开放。住建部明确下一步方向，年度计划执行中。

- **叙事框架：** 民生框架。判定依据：命中民生词典词"养老""公共服务"（"补齐社区养老、托育、便利店、停车、绿化等服务短板""完善社区的养老、托育等公共服务设施"）。无框架迁移。

- **待验证：** 住建部完整社区建设扩面提质增效工程实施方案；年度约1000个社区计划收官数据（检验社区服务设施投资是否放量）。已纳入跟踪表主题34（首次纳入）。
