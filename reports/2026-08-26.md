## 读报指南（怎么读这份报告）

本报告为政策偏离检测日报，核心是跟踪“规划承诺 vs 联播叙事 vs 现实兑现”的偏差。固定口径如下：

| 维度 | 口径 |
|------|------|
| 层级 | A=总书记讲话/最高层部署；B=专题报道+部委文件；C=常规报道+部委文件/规划；D=简讯快讯 |
| 首次性 | NEW=首次出现；PROGRESS=已有方向新进展；REPEAT=重复 |
| 具体性 | S1=量化指标+时间表+资金/项目；S2=有量化指标或时间表；S3=只有表态 |
| 政策窗口 | 开放=问题流/政策流/政治流三流齐备；接近=缺一个推力；封闭=不具备 |
| 验证窗口 | SHORT=1-4周；MID=1-3月；LONG=无明确节点 |
| 叙事框架 | 安全/竞争/民生/发展，依据框架判定词典命中词 |
| 投资假设 | 内部可证伪验证指标，不构成投资建议 |
| 框架判定依据 | 词典命中词或原文片段，空依据=待补证 |
| 生命周期事件 | 建档/框架变更/状态变更/验证等，只追加不覆盖 |

### 信号1：新型工业化融合升级与未来产业培育（十五五）

**联播原文：** 第11条——国新办“开局起步‘十五五’”系列发布会，工信部表示“十五五”时期实施一系列专项行动，加快构建以先进制造业为骨干的现代化产业体系；组织实施传统产业焕新行动；加快打造集成电路、航空航天、生物医药等新兴支柱产业，到2035年力争培育100家左右新兴产业发展示范园区、1000家左右示范企业；推动量子科技、脑机接口、具身智能等未来产业成为新的经济增长点；将6G作为“十五五”时期重中之重。

**趋势判断：** 这是“十五五”产业政策的首次系统性施工图披露，将纲要第二篇“建设现代化产业体系”细化为可操作的专项行动与量化目标。与主题5（未来产业布局）、主题51（6G）形成直接承接，标志着产业政策从“方向表述”进入“实施准备”阶段。

**投资假设：** 先进制造业与未来产业获政策倾斜 → 集成电路、航空航天、生物医药等新兴支柱产业及量子科技、脑机接口、具身智能等未来产业投资与产出加速。

**层级/首次性/具体性/验证窗口：** B / NEW / S1（量化指标）/ MID（2035年目标，近期看专项行动落地）

**政策窗口：** 开放——问题流（产业升级压力）、政策流（专项行动）、政治流（十五五开局）三流齐备。

**叙事框架：** 竞争框架 + 判定依据（“加快打造”“新兴支柱产业”“未来产业成为新的经济增长点”）

**待验证：** 检验投资假设还差“示范园区/示范企业名单发布”或“未来产业先导区/重大专项实施方案”证据，已纳入跟踪表主题55（首次纳入）。
