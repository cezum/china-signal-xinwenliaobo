## 读报指南（怎么读这份报告）

> 首次阅读先看这里，老读者可跳过。本报告从联播中提取的是"政策信号"——有政策含义、可追踪验证的事件，不是每条新闻都算。跟踪表中的"主题N"为信号编号，主题详情及历史时间线见 `reference/initial_signal_tracking_table.md`。

| 口径 | 含义 |
|------|------|
| 层级 | 信号由谁发出：A=联播头条+习近平讲话/批示；B=专题报道+部委文件；C=常规报道+部委文件/规划；D=简讯快讯 |
| 首次性 | 是不是新方向：NEW=首次出现的新信号；PROGRESS=已有方向的新进展；REPEAT=重复无新增 |
| 具体性 | 有没有抓手：S1=量化指标+时间表+资金/项目；S2=方向明确但缺细节；S3=只有方向表态 |
| 政策窗口 | 出细则的概率：开放=问题、方案、政治时机三流齐备，短期落地概率高；接近=差一个推力；封闭=暂不具备条件 |
| 验证窗口 | 多久能验证：SHORT=1-4周；MID=1-3个月；LONG=无明确节点 |
| 叙事框架 | 联播报道的话术基调：安全框架（守住底线/自主可控）、竞争框架（抢占/引领）、民生框架（兜底/保障）、发展框架（培育/壮大） |
| 投资假设 | 每个主题一句话的投资/产业逻辑；跟踪表的验证日期就是检验这句假设的时点，不是事件打卡 |
| 框架判定依据 | 框架标签的证据（命中词典词或原文片段）；无依据=待补证，词典见 `reference/framework-dictionary.md` |

**验证源分类（v2.4）**：验证点是"联播报道某事件"的为**联播型**，证据仅限当日联播原文；验证点是官方/外部事实（如"商务部发布数据""国务院印发文件"）的为**外部型**，当日联播未出现时可引用官方公开信息核验（须写明机构、发布日期、来源标题或链接），禁止无出处推测。

"十五五"指2026-2030年国民经济和社会发展第十五个五年规划（纲要2026年3月发布，18篇62章）。本报告每条信号都标注其对纲要哪一篇哪一章的落地关系：**主题首次纳入跟踪，不等于政策方向是新的**——多数是纲要既有部署进入实施或见效阶段。

## 信号详析

### 信号一：习近平署名文章定调"灾害治理向事前预防转型"——防灾减灾救灾进入工程化投入期

- **联播原文：** 第1条——8月16日出版的第16期《求是》杂志发表中共中央总书记、国家主席、中央军委主席习近平的重要文章《提高防灾减灾救灾能力》。文章指出，要推动灾害治理向事前预防转型。坚持源头管控，将安全韧性要求贯穿国土空间规划及各类建设规划之中；强化工程治理，合理提高重要城市和灾害多发地区关键基础设施设防标准，**加紧补齐北方地区防洪排涝抗灾基础设施短板**。健全监测预警体系，提高预警的及时性、精准性、通达性。要充分发挥新型举国体制优势，推动应急领域科技创新和产业创新，深入开展自然灾害基础研究，推进关键技术攻关。完善基层应急救援力量体系，强化应急场所建设和物资装备保障。

- **趋势判断：** 这篇文章的产业意义在于把防灾减灾从"事件驱动"（出了灾再救）切换为"规划驱动"（事前设防）。三个具体抓手值得盯：一是"安全韧性要求贯穿国土空间规划"——意味着新基建、城市群、重大工程的安全设防标准将整体上修；二是"补齐北方防洪排涝短板"——北方城市内涝治理从表态变为点名任务，对应排水管网、泵站、调蓄设施等实物投资；三是"应急领域科技创新和产业创新"写进最高层文章——应急装备、监测预警（气象/水文/地灾）、低空应急等方向获得政策背书。与主题24（安全生产专项整治）的区别：主题24 是企业端事故驱动的合规需求，本条是政府端规划驱动的防灾工程投入，传导路径独立。

- **投资假设：** 最高层定调"灾害治理向事前预防转型"+明确补齐北方防洪排涝短板 → 城市防洪排涝工程（管网/泵站/堤防）、气象水文地质灾害监测预警装备、应急产业（救援装备/物资/低空应急）订单加速。

- **层级/首次性/具体性/验证窗口：** A / NEW / S2（方向明确、点名北方防洪排涝，但无量化指标与时间表） / MID（1-3个月内水利部/应急管理部专项方案或防洪排涝工程开工可见）

- **政策窗口：** 开放。问题流=8月河南江苏汛情（许昌/周口溃口、太湖超保证水位）；政策流=《求是》署名文章；政治流=最高层直接部署。三流齐备，短期出细则概率高。

- **叙事框架：** 安全框架。判定依据：词典命中"安全/应急/风险防范/底线"——原文"站在统筹高质量发展和高水平安全的战略高度""健全监测预警体系""有效压降存量风险、遏制新增风险"。与主题24、26（生态保护）、30（核电）安全框架一致，无漂移。

- **待验证：** 应急管理部/水利部发布防灾减灾或防洪排涝专项实施方案；联播报道北方防洪排涝重大工程开工或应急监测预警体系建设重大进展（检验"事前预防"是否转化为政府防灾工程订单）。已纳入跟踪表主题35（首次纳入）。

### 信号二：农村物流体系升级与"客货邮"融合——农业农村现代化的流通维度首次量化

- **联播原文：** 第6条——今年以来，各地持续升级农村物流体系，精准破解城乡流通堵点。《加快农业农村现代化"十五五"规划》提出，支持农村寄递物流设施共建共享，推动"客货邮"融合发展。在贵州平塘，30辆"客货邮"公交专用新车近日正式投入运营，一趟车，既载人，也运货，让偏远山村也有了便捷的物流通道。冷链物流直达田间，四川泸州晚熟荔枝从采摘到进入冷链车的时间从此前一两个小时缩短到15分钟以内，保鲜期可延长到20天以上。中国物流与采购联合会的最新数据显示，**7月份全国电商物流农村业务量同比增长超过20%**。

- **趋势判断：** 农村物流是《加快农业农村现代化"十五五"规划》（第八篇）落地的新维度，与主题21（粮食产能/种业/高标准农田）同规划不同赛道。这条信号的价值在于"需求端数据先行"：7月电商物流农村业务量+20%证明农村消费流通的真实动能，而规划点名的"寄递物流设施共建共享+客货邮融合"是供给端补齐的明确政策方向，且已有项目落地（贵州平塘30辆客货邮公交）。冷链直达田间（产地预冷、揽收点下沉）则是生鲜电商与冷链设备的直接订单来源。城乡流通是内需体系（纲要第五篇统一大市场）与乡村振兴（第八篇）的交汇点。

- **投资假设：** 《加快农业农村现代化"十五五"规划》支持农村寄递物流设施共建共享+客货邮融合 → 县域物流枢纽/客货邮公交线路、冷链物流（田间直达）、农村电商快递网络投资加速；7月电商物流农村业务量+20%验证需求端。

- **层级/首次性/具体性/验证窗口：** B / NEW / S1（规划文件+20%量化数据+30辆公交项目落地） / MID（1-3个月内客货邮示范工程名单或农村冷链专项可验证）

- **政策窗口：** 开放。规划已印发（政策流）、项目已落地（贵州）、数据已佐证（+20%），三流齐备。

- **叙事框架：** 发展框架。判定依据：词典命中"升级/加快构建"（发展框架）——原文"持续升级农村物流体系，精准破解城乡流通堵点""冷链物流直达田间""加快补齐城乡流通短板"。主叙事为流通体系市场化升级，无安全/竞争语境，单标签。

- **待验证：** 交通部/国家邮政局发布客货邮融合发展示范工程名单或农村冷链/寄递物流专项实施方案；联播报道电商物流农村业务量月度增速延续20%+（检验农村物流投资是否放量）。已纳入跟踪表主题36（首次纳入）。

### 信号三：基层中医药服务能力提升——《医疗卫生强基工程》中医药专项落地

- **联播原文：** 第10条——近期，各地落实《医疗卫生强基工程中医药行动方案》部署，以创新基层服务模式、专家下沉等多种形式，提升基层中医药服务能力。江苏省常熟市村级"中医阁"投用，医护人员每周六上门服务，为失能卧床老人量身定制中医服务包；北京市丰台区中医医院烧伤整形与创面修复科联动27家社区卫生服务中心，将优质中医创面修复技术下沉至社区。截至2025年底，全国县级中医医院数量达到2238家，基层医疗卫生机构中医馆覆盖率接近98%，99%的乡镇卫生院和社区卫生服务中心能够提供中医药服务，基层医疗卫生机构中医馆的中医医师配备率已达95.5%。

- **趋势判断：** 这条信号的产业含义在于"覆盖率见顶后的服务升级"：中医馆覆盖率98%、医师配备率95.5%，说明"有没有"的问题基本解决（存量建设接近饱和），下一步增量在"好不好"——上门送诊（村级中医阁）、特色专科下沉（创面修复联动社区）、中医康复护理（帕金森卧床患者场景）。对应需求：基层中医诊疗与康复设备配置、中药饮片/配方颗粒基层配送供应链、中医智能辅助诊疗系统（弥补基层医师能力短板）。与长护险（主题16）、完整社区（主题34）同属民生服务下沉主线，中医药是其中供应链最明确的一条。

- **投资假设：** 《医疗卫生强基工程中医药行动方案》落地、中医馆覆盖率98%接近饱和后转向服务下沉 → 基层中医诊疗/康复设备配置、中药饮片与配方颗粒供应链、中医智能辅助诊疗系统需求释放。

- **层级/首次性/具体性/验证窗口：** B / NEW / S1（2238家/98%/99%/95.5%四项量化） / MID（1-3个月内中医药局年度进展或中医馆设备配置标准可验证）

- **叙事框架：** 民生框架。判定依据：词典命中"医疗/服务"（民生框架）——原文"提升基层中医药服务能力""破解农村高龄、失能群体就医难题""打通便民就医的'最后一公里'"。与主题16、34等民生主题一致，无漂移。

- **待验证：** 国家中医药管理局发布基层中医药服务能力提升工程年度进展/中医馆建设新目标；联播报道中医药强基专项采购、中医馆设备配置标准落地（检验基层中医药设备与供应链需求是否放量）。已纳入跟踪表主题37（首次纳入）。
